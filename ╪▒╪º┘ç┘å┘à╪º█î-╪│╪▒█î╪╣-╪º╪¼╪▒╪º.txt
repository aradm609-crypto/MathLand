راهنمای سریع اجرای MathLand در ویندوز

۱) فایل ZIP را از حالت فشرده خارج کنید.
۲) وارد پوشه project شوید.
۳) در نوار آدرس پوشه بنویسید cmd و Enter بزنید تا پنجره ترمینال در همان پوشه باز شود.
۴) این دستور را اجرا کنید:
   npm.cmd install
۵) پس از پایان نصب، این دستور را اجرا کنید:
   npm.cmd run dev
۶) نشانی‌ای را که ترمینال نشان می‌دهد (معمولاً http://localhost:5173) در مرورگر باز کنید.

برای بستن سایت، در پنجره ترمینال کلیدهای Ctrl و C را بزنید.
پوشه نسخه قبلی و نسخه پشتیبان خود را تا وقتی نسخه جدید را بررسی نکرده‌اید حذف نکنید.
